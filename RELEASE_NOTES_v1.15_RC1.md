# MELNIKOV MUSIC PLAYER — Classic Edition v1.15 RC1

**Release candidate 1 · Free desktop audio and video player for Windows**

The next version of MELNIKOV MUSIC PLAYER Classic Edition is available in separate **English** and **Russian** Windows installers.

## What's included

- Updated modular desktop player interface.
- Independent Playlist, Video and Visualization windows.
- **MELNIKOV VISUALIZATION v1.6** integrated into the v1.15 player, with up to **490 visual variations**.
- Local audio and video playback, playlist management and visualization.
- **Two MELNIKOV MUSIC albums included with the installers.** These bundled music collections explain the large installation package size.

## Downloads

Upload both release assets:

| Edition | Exact installer filename |
| --- | --- |
| Russian | `MMP_Classic_RU_v1.15_RC1_Setup.exe` |
| English | `MMP_Classic_EN_v1.15_RC1_Setup.exe` |

Both installer files are approximately **337 MB** each. They are separate language editions, **not** a language toggle within one installer.

**Note:** v1.15 RC1 is a release candidate. Keep it marked as a **pre-release** until final testing is complete.

## Visualization plugin

**MELNIKOV VISUALIZATION v1.6 is already integrated into Classic v1.15.** No separate visualization plugin installation is required for this version.

For Classic v1.14, MELNIKOV VISUALIZATION must be downloaded and installed separately if desired. A standalone AIMP/Winamp plugin distribution will follow independently; it is **not** included in this GitHub release.
